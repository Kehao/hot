利用 GPT‑5.6 推进性价比前沿

原始标题：Breaking: Advancing the price-performance frontier with GPT‑5.6
⚡ 一句话看懂：利用 GPT‑5.6 推进性价比前沿。来源：Hacker News AI

昨天，我们分享了 GPT-5.6 如何帮助其提高运行效率。

今天，我们以更低的 GPT-5.6 Luna(在新窗口中打开) 和 Terra(在新窗口中打开) 价格以及 API 中的 GPT-5.6 Sol 更快的性能将这些收益传递给客户。

总之，这些更新可以帮助客户从人工智能投资的每一美元中获得更多收益，并在时间紧迫时更快地采取行动。

从今天开始，我们最快、最实惠的型号 GPT‑5.6 Luna 的成本将降低 80%，而我们适合日常工作的平衡型号 GPT‑5.6 Terra 的成本将降低 20%。

Luna 和 Terra 的较低价格也反映在使用 Codex 和 ChatGPT Work 时如何根据付费订阅计算使用量。

Luna 为企业提供了一种更具成本效益的方式来以极高的质量水平处理大量工作。

它可以使用工具并完成多步骤工作流程，使更广泛的人工智能应用程序能够大规模运行。

OpenAI 确保 AGI 造福全人类的使命的核心是让先进的智能变得更加丰富和实惠。

这些变化将这一承诺付诸实践。

它们反映了我们的模型构建、服务和运行方式多年来的改进。

我们还在 API 中引入了快速模式，该模式取代了我们的优先处理产品。

对于 GPT‑5.6 Sol，快速模式现在的速度比标准处理快 2.5 倍，价格是标准处理的两倍，而智能程度没有变化。

快速模式向后兼容：标记优先级的请求将自动使用快速模式。

有效地使用人工智能始于结果。

风险、错误成本、紧迫性和规模决定了智能、速度、可靠性和成本之间的正确平衡。

这种平衡可以从工作流程的一个步骤改变到下一个步骤。

GPT-5.6 为企业提供了更大的空间来优化该等式。

Luna 的性能可与一年前的前沿型号相媲美，每项任务的成本约为 6 美分，速度却是一年前的近九倍。

在专业工作方面，根据 Agents’ Last Exam 的衡量，Luna 的表现优于《神鬼寓言 5》，但每项任务的估计成本低了近 99%。

在实践中，企业可以定义他们所需的结果和质量标准，然后使用评估来确定额外的智能在哪些方面可以实质性地改善结果，以及在哪些方面更快、更低成本的处理可以提供相同的质量。

例如，编码工作流程可能使用 Sol 来解决不确定性并定义计划，然后使用 Luna 来实施明确的更改、编写和运行测试以及评估结果。

另一个工作流程可能需要不同的平衡。

GPT-5.6 系列扩大了这些选择的范围。

企业可以在每个阶段应用最大程度的有用情报，同时为其创造的价值支付适当的价格。

提供这种灵活性首先要提高模型背后的每一层的效率。

我们的效率优势来自于改进模型、运行模型的推理系统以及将模型连接到工具和上下文的代理工具。

GPT-5.6 模型在工作中采取更直接的路径。

更好的路由可以保持硬件的生产力，优化的生产软件可以更有效地生成令牌，而更智能的上下文管理可以帮助代理避免重复已完成的工作。

总之，这些改进让我们能够使用相同的计算完成更有用的工作，从而减少每个结果所需的时间、令牌和成本。
