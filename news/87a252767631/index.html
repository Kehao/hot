萨姆·奥尔特曼不需要再提起诉讼

OpenAI 在这一年的大部分时间里都卷入了一场又一场的诉讼，其中包括来自世界首富的诉讼。

但上周五，该公司遭遇了迄今为止最引人注目的法律诉讼之一——来自苹果公司。

OpenAI 昂贵的硬件赌注就是赌注。

萨姆·奥尔特曼不需要再提起诉讼 然而，苹果公司有关窃取商业机密的指控可能需要数年时间才能提起诉讼。

萨姆·奥尔特曼不需要再提起诉讼 然而，苹果公司有关窃取商业机密的指控可能需要数年时间才能提起诉讼。

苹果向北加州联邦法院提起针对 OpenAI 的诉讼，指控前苹果员工“为了 OpenAI 的利益窃取苹果的商业机密”。

这份长达 41 页的投诉称，苹果对其“产品开发、制造、供应链、技术研究和其他创新保密”，并且“苹果硬件业务的商业秘密共同构成了所有美国企业中最有价值的知识产权之一。

” 这些指控提到了三名前苹果员工：唐坦，Apple Watch 前副总裁，在苹果工作了 24 年，之后成为 OpenAI 的首席硬件官（在 OpenAI 收购了 Jony Ive 的硬件公司 io 之后）； Chang Liu，前 iPhone 系统电气工程师，在加入 OpenAI 之前在 Apple 工作了 8 年；还有另一位前苹果员工 Yu-Ting “Alyssa” Peng，她也加入了 OpenAI。

（人们对彭的苹果任期知之甚少。

）这起诉讼提出了很多疯狂的主张，其中包括据称谭要求未来的员工在 OpenAI 面试期间将苹果硬件带到办公室外面进行“展示和讲述”，并指导苹果员工如何避免公司的离职安全程序。

（目前尚不清楚 OpenAI 的设备中可能包含了苹果硬件相关的哪些商业机密（如果有的话），因为 OpenAI 尚未公开展示产品。

） McKool Smith 商业秘密实践领域联合主席、该公司 AI Litigation Tracker 的作者 Avery Williams 告诉 The Verge，他认为 OpenAI 的法律麻烦还远未结束。

“他们已经被起诉了很多次。

[但是]在我们得到高等法院关于人工智能训练合理使用问题的裁决之前，OpenAI 不会摆脱困境。

这是一个价值数万亿美元的问题。

” 这起诉讼是 OpenAI 面临的又一个障碍，在过去的六个月里，OpenAI 与竞争对手在美国军事红线问题上发生了戏剧性的变化，对与美国政府合同的抗议，与 OpenAI 前联合创始人埃隆·马斯克 (Elon Musk) 的旷日持久的法律斗争，以及与 Anthropic 就哪个前沿实验室将首先进行 IPO 的竞赛——更不用说一系列诉讼，其中一些诉讼来自马斯克本人。

另一项仍在进行中的诉讼是由 16 岁的 Adam Raine 的家人提起的，他在向 ChatGPT 吐露心声后自杀身亡。

此外，《纽约时报》和其他出版商对 OpenAI 提起了长期诉讼，指控其侵犯版权。

苹果提起诉讼的时机对于 OpenAI 来说也远非理想：该公司正准备上市，上个月已向 SEC 秘密提交了 S-1 表格；它面临着投资者要求扭亏为盈的压力；它还删除了一堆“支线任务”，以便专注于企业和编码等关键收入驱动因素。

不过，也许最重要的是，在斥资近 65 亿美元收购著名苹果设计师 Jony Ive 的硬件初创公司 io（并处理了另一家名为 Iyo 的公司的诉讼）之后，它正准备在 2027 年发布一款大肆宣传的硬件设备。

苹果可能因在人工智能方面落后而闻名，但它在硬件方面一直处于领先地位，而 OpenAI 却享有相反的声誉。

业界普遍认为“硬件很难”；要找到证据，只需看看过去被过度炒作的人工智能设备的墓地，比如人道人工智能别针。
